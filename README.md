# 🎬 Movie Recommendation App

An interactive Content-Based Movie Recommender built with Python, Streamlit, and Scikit-Learn.

🚀 **[Live Demo](https://movie-recommender-app.streamlit.app/)**

## ✨ Features

* **Content-Based Filtering:** Recommends similar titles using TF-IDF text features and Cosine Similarity.
* **Match Percentage Score:** Displays exact similarity scores for top recommendations.
* **Instant Interactive UI:** Dynamic filtering with zero page reloads.

## 🛠️ Tech Stack

* **Framework:** Streamlit
* **Machine Learning:** Scikit-Learn (`TfidfVectorizer`, `cosine_similarity`)
* **Data Handling:** Pandas
